# 💰 React Expense Tracker App

A simple and lightweight Expense Tracker built with React. Users can add income and expenses, track their balance, toggle between light and dark modes, and delete entries. All data is stored in the browser using `localStorage`.

## 🚀 Features

- 📈 Add income or expense items
- 💸 Real-time balance summary
- 🌓 Toggle between light and dark themes
- 🗑️ Delete individual items
- 💾 Saves data locally using `localStorage`
- 🔁 Automatically updates UI based on inputs

## 🛠️ Built With

- React
- HTML/CSS
- JavaScript (ES6)
- LocalStorage for persistent data
